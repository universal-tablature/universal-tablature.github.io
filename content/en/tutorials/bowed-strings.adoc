[source,utab]
----
slur { D4 q; E4 q; F#4 q; G4 q }
vibrato { A4 h }
pizzicato { D4 q }
G4 q rearticulate
----

The violin model realizes ordinary pitches against its strings and standard
tuning. `slur`, `vibrato`, and `pizzicato` remain named techniques on their
resolved events; `rearticulate` explicitly requests a fresh attack. MIDI gives a
useful approximation, while UTAB retains the distinctions needed by notation,
training, and instrument-aware renderers.

Technique blocks are validated against the selected instrument profile. For
example, `pizzicato` is valid for `Violin` but is not silently accepted for an
instrument whose profile does not declare it.
