== Instrument, tuning, and scale are separate

[source,utab]
----
import instruments.oud.arabic
import std.naming.arabic.degrees

scale D MaqamBayati
instrument oud : ArabicOud as "Arabic oud"
----

`ArabicOud` carries its six-course C tuning in the instrument module, so it is
usable without an extra tuning import. `MaqamBayati` is a bundled seven-degree
cent table used to resolve this example. It is a documented reference
approximation, not a mandatory or universal tuning.

== Select contextual names explicitly

[source,utab]
----
phrase ascent {
    using notation ArabicDegrees
    duka[3] q
    sikah[3] q
    jaharkah[3] q
    nawa[3] q
}
----

Importing `std.naming.arabic.degrees` does not globally reinterpret identifiers.
`using notation ArabicDegrees` selects the table in this phrase. The names bind
to degree identities; the active scale supplies their pitch and intonation.
Consequently `sikah` here is contextual rather than a universal fixed frequency.

For serious repertoire, the score should additionally document the source,
regional and historical practice, chosen intonation, editorial decisions, and
review by an appropriate practitioner. Maqam behavior also includes melodic
development, focal tones, ajnas, and modulation beyond this scale exercise.
