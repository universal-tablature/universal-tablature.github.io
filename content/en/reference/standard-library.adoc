The Composer standard library is a set of `.utab` modules bundled with the
compiler. Import a module by its declared name; file paths are an implementation
detail.

[source,utab]
----
import instruments.piano
import instruments.guitar
import std.harmony.roman

instrument piano : Piano
instrument guitar : Guitar
----

[NOTE]
====
This overview describes the current `0.1-draft` library. Names and catalogue
coverage may change while the language and instrument model evolve.
====

== Convenience import

`instruments.standard` imports the complete instrument collection, including
the alternate guitar tunings. Explicit imports make dependencies clearer and
are preferable when a score only needs a few models. Every applicable
instrument module carries at least one usable standard tuning or fingering;
scores do not need a second “completion” module. Separate modules are reserved
for optional alternatives such as Drop D and DADGAD.

== Capability profiles

Profiles describe what an instrument can actuate and which interactions and
techniques it supports. Scores usually import instrument modules rather than
profiles directly; model-authoring modules use these profiles as their base.

[cols="2,3",options="header"]
|===
|Module |Exported profiles

|`profiles.core`
|`FrettedStrings`, `PluckedCourses`, `PluckedOpenStrings`,
`FretlessBowedStrings`, `Keyboard`, `SingingVoice`

|`profiles.nyckelharpa`
|`KeyedBowedStrings`

|`profiles.percussion`
|Profiles for unpitched, pitched, tunable, pressure-controlled, shaken,
scraped, lamellophone, and damped gong/bar instruments

|`profiles.wind`

`MouthOrgan`, `BellowsFreeReed`, and `DoubleReedWind`
|===

== Historical and regional strings

`instruments.lute.renaissance` exports `RenaissanceLute`,
`RenaissanceLuteEightCourse`, `RenaissanceLuteTenCourse`,
`BaroqueLuteElevenCourse`, `BaroqueLuteThirteenCourse`,
`ArchluteFourteenCourse`, `TheorboFourteenCourse`, and `RenaissanceVihuela`.
It also provides equal-temperament, Pythagorean, quarter-comma meantone, and
sixth-comma meantone scale definitions, plus model tunings.

`instruments.oud.arabic` exports `ArabicOud`, its default tuning, and the
`MaqamRast`, `MaqamBayati`, `MaqamHijaz`, `MaqamNahawand`, `MaqamKurd`,
`MaqamAjam`, and `MaqamSaba` cent-based scales.

`instruments.lyre.sammu` exports `NineStringSammu` and a reconstructed tuning.
The link:/en/tutorials/hurrian-hymn/[Hurrian Hymn tutorial] uses this model.

`instruments.nyckelharpa` exports `KromatiskNyckelharpa`, `Kontrabasharpa`,
`Silverbasharpa`, `Oktavharpa`, `Moraharpa`, `Esseharpa`, and `Vefsenharpa`, each
with a reference tuning.

== Wind and free-reed instruments

The wind catalogue is split into focused modules. `instruments.wind` is a
convenience umbrella that imports all three.

`instruments.wind.woodwinds` exports:

* `SopranoRecorder`, `AltoRecorder`, `TenorRecorder`, and `BassRecorder`
* `ConcertFlute` and `Piccolo`
* `BbClarinet` and `BassClarinet`
* soprano, alto, tenor, and baritone saxophones
* `Oboe`, `EnglishHorn`, `Bassoon`, and `Contrabassoon`

`instruments.wind.brass` exports `BbTrumpet`, `TenorTrombone`, `BassTrombone`,
`DoubleHorn`, `Euphonium`, and `Tuba`.

`instruments.wind.free-reeds` exports `C10DiatonicHarmonica`, `PianoAccordion`,
and `AngloConcertina`. Applicable wind models carry a standard fingering map in
the same module as the model.

== Percussion

`instruments.percussion` exports `SnareDrum`, `BassDrum`, `Tambourine`,
`Triangle`, `DrumKit`, `Xylophone`, `Marimba`, `Glockenspiel`, `Vibraphone`, and
`Timpani`, plus common cymbals, hi-hat, toms, tam-tam, bells, blocks, claves,
shakers, and castanets.

Regional families are grouped by playing system rather than one generic
“world percussion” model:

`instruments.percussion.arabic`:: Darbuka, riq, daf, and bendir variants.

`instruments.percussion.indian`:: Tabla, pakhawaj, mridangam, kanjira, ghatam,
dholak, and dhol.

`instruments.percussion.folk-drums`:: Djembe, dunun, talking drum, and shekere.

`instruments.percussion.latin`:: Congas, bongos, timbales, cajón, surdo,
pandeiro, and güiro.

`instruments.percussion.east-asian`:: Specified taiko, janggu, buk, and kendang
configurations.

`instruments.percussion.gamelan`:: Bonang, saron, gender, gong ageng, and
kempul with ensemble-aware layout and damping metadata.

`instruments.percussion.pitched-world`:: Steelpan, handpan, mbira, kalimba,
and balafon models with explicit layouts or reference tunings.

[cols="2,4",options="header"]
|===

|`instruments.traditional-chinese`

|`instruments.traditional-african-strings`
|Twenty-one-string kora, six-string donso ngoni, and Xhosa uhadi musical bow

|`instruments.traditional-latin-american`
|Capoeira berimbau, charango, Venezuelan llanero cuatro, quena, and paired siku

|`instruments.traditional-final`
|Bandoneon, Great Highland bagpipe, French hurdy-gurdy, Appalachian and
hammered dulcimers, plus selected vocal-technique models
|===

These are concrete constructions, not claims that one model represents an
entire culture or instrument family. Module definitions record physical
topology, controls, ranges, and—where applicable—a default tuning or fingering.

== Tunings

[cols="2,3",options="header"]
|===
|Module |Contribution

|`tunings.guitar.drop`
|Adds the `dropD` tuning to `Guitar`.

|`tunings.guitar.dadgad`
|Adds the `dadgad` tuning to `Guitar`.
|===

Instrument modules also carry their default tunings. A score can select a
particular model extension when the compiler and authoring API expose tuning
selection for an instance.

== Musical symbols and utility constants

`std.harmony.roman`:: Major uppercase and minor lowercase diatonic chord
constants `I` through `VII`; `vii` is diminished.

`std.naming.solfege.fixed`:: The `FixedSolfege` table: `do` through `ti` as
absolute pitch letters with octave registers.

`std.naming.solfege.movable`:: The `MovableSolfege` table: `do` through `ti`
mapped to degrees `@1` through `@7` in the active scale.

`std.naming.arabic.degrees`:: The contextual `ArabicDegrees` table with
`qarar_rast`, `duka`, `sikah`, `jaharkah`, `nawa`, `husayni`, `awj`, and
`kirdan`. Their intonation follows the active scale.

`std.naming.western.english` and `std.naming.western.german`:: Explicit English
and German letter-name tables. Importing a naming module never selects it;
scores use `using notation Name` in a lexical scope.

`std.harmony.chords`:: Standard triad, seventh, and suspended chord-quality
values represented as open interval collections.

`std.harmony.bass`:: Reusable `roots`, `rootFifth`, and `arpeggio` bass patterns.

`std.midi`:: Symbolic constants for all 128 General MIDI programs and the
standard channel-10 percussion note names.

== Qualified names and stable IDs

Imported public symbols can be referenced by their short names when
unambiguous. Qualified names can disambiguate symbols from different modules.
Instrument catalogue declarations also carry quoted stable IDs such as
`"instrument:guitar:classical-six-string"`; these identify catalogue entities
independently of the source-level symbol name.
